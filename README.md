# SOFT Downloaders

Site público e independente para analisar links diretos de mídia e baixar conteúdo que o usuário possui ou tem autorização para usar.

## Escopo inicial

- Área **Mídias** para fotos e vídeos públicos compatíveis.
- Área **Vídeo para MP3** para converter vídeos compatíveis em áudio MP3.
- Área **Músicas** para faixas, álbuns e playlists de SoundCloud, Bandcamp, Audius e BandLab, além de playlists do YouTube e links diretos de áudio.
- Álbuns/playlists carregam com todas as faixas selecionadas; o usuário pode desmarcar as que não quiser e baixar as selecionadas em um ZIP organizado por ordem e nome.
- Área **Thumbnail** para capas de vídeos e streams compatíveis.
- Interface estática, responsiva e sem anúncios.
- Integrações sociais futuras somente via autorização oficial da conta.
